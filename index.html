Fix · Cursed Survival

Cursed Survival Rarity Outline Fix 1.0

In Cursed Survival every dropped item shows a grey outline, however rare it is. This brings back the normal rarity colours, the same as in regular Survival.

  • Cursed Survival only: other modes are untouched
  • Any map and any relic, Mister Peeks Mayhem too

Install any of them

  1. Set up Kronos and run its launcher at least once.
  2. Download the mod's zip, then close Black Ops 7 and KronosLauncher.
  3. Extract the zip into C:\Kronos\cod25\kronos\mods. Each mod is one folder there.
  4. Launch the game through Kronos as usual. To remove a mod, delete its folder.
